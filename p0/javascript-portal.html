Part 1

Read JavaScript

Understand JavaScript fundamentals including variables, functions, event handling, DOM manipulation, asynchronous programming, and modern ES6+ features. Learn how JavaScript enables dynamic page behaviors, form validation, API communications, user interactions, and client-side data processing. Master the bridge connecting static HTML/CSS into fully interactive web applications delivering rich user experiences responsive to real-time input and data changes.

Part 2

Code JavaScript

Develop practical JavaScript skills through focused exercises covering DOM selection, element modification, event listener attachment, form handling, and AJAX operations. Practice writing clean, readable code following best practices for variable scoping, function decomposition, error handling, and code organization. Build confidence implementing real-world features like modal dialogs, sliders, form validations, and dynamic content loading in your own projects.
