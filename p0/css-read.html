What is CSS?

CSS (Cascading Style Sheets) defines the visual presentation and styling of HTML documents. It controls colors, fonts, spacing, layout positioning, responsive behavior, and animations. CSS separates content from presentation, enabling designers to create consistent visual experiences across multiple pages while developers maintain clean, semantic HTML structures without embedded styling clutter.

Linking to HTML

CSS connects to HTML through three methods: external stylesheets linked via the link element in the head, internal styles using the style element within head, or inline styles applied directly to HTML elements via the style attribute. External stylesheets promote reusability and caching, making them ideal for production websites with multiple pages sharing consistent visual designs throughout the entire application.

Syntax

CSS syntax consists of selectors targeting HTML elements, followed by declaration blocks containing property-value pairs enclosed in curly braces. Properties define what aspect to style (like color, font-size, or margin), while values specify how to style it (like blue, 16px, or 20px). Multiple declarations within a block separate with semicolons, and comments begin with forward slashes ending with asterisks.

Common classes

Common CSS classes follow naming conventions like BEM or utility-first approaches for maintainability. Classes starting with verbs describe actions (clickable, hidden), adjective-noun combinations denote states (active-user, disabled-button), or single letters indicate purposes (c, m, u). Semantic naming improves code readability, enabling team members to quickly understand element purposes and relationships across large, complex stylesheet architectures built over time.

Pseudo classes

Pseudo-classes target elements based on their state or position rather than explicit selectors. Hover states trigger on mouse interaction, focus states activate during keyboard navigation, visited links change after clicking, and :first-child/:last-child select positional siblings. Dynamic pseudo-classes enable interactive feedback without JavaScript, while structural pseudo-classes simplify selecting groups based on document tree positions instead of manual class additions.
